# Multigrid Examples

This section provides pre-configured example routines to demonstrate the multigrid method applied to diffusion-reaction equations on various metric graphs. 

The following functions can be used to run full multigrid cycles on predefined graph topologies (e.g., star graphs, Barabási-Albert graphs), extract performance metrics, and evaluate convergence rates.
